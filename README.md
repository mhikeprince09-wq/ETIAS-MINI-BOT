🛠️ Installation

1. Clone the repository:

```bash
git clone https://github.com/etiasgroup00-star/etias-bot
cd etias-mini-bot
```
2. Install dependencies:

```bash
npm install
```
Make sure to configure `config.js` and `Main.js` properly.

3. Start the bot

```bash
node main.js
```
or with PM2:

```bash
pm2 start main.js --name etias-bot
```

Usage

- Scan the QR code with your WhatsApp device on firs
t run.
- Use commands with your set prefix (default: `.`).
- Example commands:

```
.menu      - Show the main menu 
.ping      - Check if bot is online
.play <song name>  - Download song from YouTube
.kick @user - Remove user from group
```
